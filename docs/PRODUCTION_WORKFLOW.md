# Production workflow

1. **Research:** record source URL, publisher, title, access date, relevant notes and usage terms. Map every factual claim to sources.
2. **Script:** hook, clear explanation, escalating visual beats and payoff. Separate narration from visual direction.
3. **Visual direction:** split into visual ideas, not mechanically one image per sentence. Each shot records environment, action, camera, motion method and required assets.
4. **Artwork:** use approved character references. Separate backgrounds, props and poses where useful. Keep generated candidates in work folders; promote selected assets only after review.
5. **Animation:** prefer reusable 2D rigs for recurring actions, keyframed poses for expressive moments and 2.5D layers for parallax. Use AI image-to-video selectively. Camera zoom over a still image does not count as character animation.
6. **Audio:** create narration, align shot durations/captions, then add licensed music and SFX below narration.
7. **Render:** produce one approved MP4 per shot and add its path and approval to storyboard/shots.json. No still-image fallback.
8. **QC:** fact-check, check identity, action-to-narration match, visible motion, audio, captions, aspect ratio and playback. Record severity/evidence.
9. **Human approval:** review final export and create reports/final_approval.json. The tool never publishes to YouTube.
